    Sparsh Touch

    Morse input. Tap for dot, hold for dash.

     

    Last action: none yet

    • Tap = dot. Hold under 4 s = dash. Pause = next letter. 8 dots = delete.
    • Hold 4 s = complete: your message is felt back in Morse. With no message, the last reply is replayed.
    • Hold 7 s = speak: AI guesses what you mean, turns it into a clear sentence, says it aloud, then clears it.
    • Hold 10 s = listen: the other person has 5 s to start talking. 3 s after they stop (or a 5 s hold) their words are felt as Morse, then you type again.

    Plan update

    Updated 2 October 2026

    The plan we first submitted was written in a hurry, because submissions were about to close. After that, we ran a short survey with people who would use Sparsh. One question stood out: how will a deaf-blind person open the app or website in the first place?

    A voice assistant cannot answer that, and a screen full of buttons cannot either. So we are changing the plan. This notice explains what changed, and what already works today.

    1. A Morse assistant instead of a voice assistant

    Sparsh will start the way each user sets it up, and can stay ready all the time. The user talks to it in Morse by tapping a short or long code anywhere on the screen. No buttons to find.

    2. Walking: the surroundings, as the user chooses

    While walking, Sparsh describes the surroundings through touch and settings the user picks. This includes obstacles and crossing a road.

    3. Conversation: what the other person says

    When the user is talking with someone, Sparsh turns the speaker's words into Morse the user can feel.

    4. Desktop: a Morse mouse

    A special Morse mouse and matching desktop software. The user enters a code they chose in advance, for example one that opens Chrome. To search, they enter another code. Sparsh then asks for the question, and the user enters it in Morse.

    5. Button phones

    We plan to support basic button phones, such as Nokia, so Sparsh does not depend on a touchscreen smartphone.

    6. Use Sparsh anytime, and the rest of the phone too

    Because of the Morse assistant, the user can reach Sparsh at any moment and use other features of the phone through it. For example, they can read and send WhatsApp messages. A deaf-blind person can do this without speaking, by entering Morse and feeling the replies. A deaf person can talk with anyone, anytime, with Sparsh turning speech into text and text into speech.

    What works today

    This prototype already has Sparsh Touch (the whole screen is one Morse button), Walk (obstacle alerts by vibration), Talk (speech to text and back), Read and Learn. The desktop Morse mouse, always-on start, richer surroundings description, using other phone features such as WhatsApp, and button phone support are planned, not built yet.
